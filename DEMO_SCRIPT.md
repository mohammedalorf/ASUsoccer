# ASUsoccer Demo Script

1. **Launch**: run `npm run dev` and open the browser URL.
2. **Dashboard**: show the counts from the seeded data.
3. **Tournaments**: open "Fall Classic" to show participating teams and points; add a team or tweak points using the form.
4. **Teams**: open "Sun Devils" to see roster; add a player with salary/goals/jersey number.
5. **Players**: create a new player via the form; return to the player list to confirm.
6. **Matches**: open the existing match, add a team if needed, update the score/winner/best player, and show events.
7. **Events**: click "Add Event", choose the match, fill type/time/player/referee, save, then delete it from the match page to show the flow.
8. **Reports**: view "Top Scorers" and "Tournament Standings" to highlight reporting queries.
